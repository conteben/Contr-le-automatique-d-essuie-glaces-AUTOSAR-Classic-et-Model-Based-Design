# Contr-le-automatique-d-essuie-glaces-AUTOSAR-Classic-et-Model-Based-Design
Contrôle automatique d’essuie-glaces adapté à l’intensité de pluie, selon l’architecture AUTOSAR Classic. Phase 1 : RTE (Rte_Read/Write/Call) et ordonnanceur type OSEK simulés en C. Phase 2 : Model-Based Design sous Simulink/Stateflow, génération du code C et des fichiers ARXML via Embedded Coder.
